Freem – Free Your Games
Freem is a lightweight, open-source game launcher for Windows built with C# and Windows Forms. It's designed with a chill, modern aesthetic and focuses on a seamless experience for managing, downloading, and playing your favorite games — all in one place.

Whether you're a fan of retro classics, indie gems, or freeware titles, Freem gives you a clean, customizable library without the bloat of modern storefronts.

✨ Features
🎨 Chill, Modern UI – Dark theme, smooth rounded corners, and an animated gradient background for a relaxed vibe.

📚 Game Library – Add games manually via the source code (simple and customizable).

📥 One-Click Download & Install – Downloads ZIP archives, extracts them automatically, and cleans up afterwards.

📊 Real-time Download Stats – See download speed, ETA, and a progress bar (both in-app and on the Windows Taskbar).

⏱️ Playtime Tracking – Automatically tracks how long you play each game and displays the total playtime.

🖼️ Dynamic Cover Art – Supports local images or direct URLs for game covers.

⚙️ Settings Panel – Change your installation path and customize the launcher.

🔍 Search & Filters – Easily find games by title or filter by "Installed" / "Not Installed".

🖱️ Context Menu – Right-click on any game card to verify files, view details, or uninstall.

📌 System Tray Support – Minimizes to the system tray and runs quietly in the background.

🛠️ Built With
C# / .NET 8 (Windows Forms) – Core framework.

System.Text.Json – For saving playtime and settings.

Windows API (ITaskbarList3) – For taskbar progress integration.

HttpClient – For asynchronous downloads and image fetching.
